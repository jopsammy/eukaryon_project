### 我们在找同行者 / We Are Looking for Companions

做出真正好用的 Agent 系统，不止是一家公司或一个团队的事（building a truly usable agent system is not a one-company matter）。它需要跨学科协作、开放讨论，以及愿意深入实践的人。

如果你认同这些判断：

- LLM 的潜力远未被真实释放——问题在工程不在基座（the issue is engineering, not the foundation model）
- Agent 系统需要治理优先的架构设计，而非一味堆叠能力（governance-first architecture, not capability stacking）
- 长程实践需要结构性的工程保障，而非依赖单次推理（structural guarantees, not reliance on single-shot reasoning）

那么欢迎加入我们。无论你是研究者、工程师还是爱好者，都可以：

- 在 GitHub 上关注和参与 [Eukaryon Project](https://github.com/jopsammy/eukaryon_project)
- 阅读我们的 [论文]({{ '/research/' | relative_url }}) 并在学术社区中讨论
- 通过实际使用和反馈帮助我们改进

Eukaryon Project 是一个开源、开放的项目。我们一起，做世界上最好用的 Agent 系统（let's build the most usable agent system together）。
