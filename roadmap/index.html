roadmap / 路线

Eureka Agent 三阶段工程路线 / Three-phase engineering roadmap of the Eureka Agent

把在 TRAE 里长出来的能力，移植为独立的 Agent 运行时核——然后解除封印，然后增强。路线会演化，但每一步都有明确的工程落点。

Port the capabilities grown inside TRAE into a standalone agent runtime kernel — then unseal, then enhance. The route evolves; every step lands on concrete engineering.

Replicate the AC Paradigm V6 capabilities validated on TRAE into a standalone agent runtime kernel, wired into real editor loops.
